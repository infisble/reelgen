# reelgen

Тестове для HOLYWATER (AI Engineer). Кидаєш ідею на 1–3 речення, на виході вертикальне відео 8–30 секунд,
де репліка з лапок звучить слово в слово.

Відповіді на питання з завдання (стек, дата-флоу, метрики, як працював з AI, що зрізав) лежать у [NOTES.md](NOTES.md).

## Як запустити

Потрібен Python 3.11+. ffmpeg окремо ставити не треба, він їде разом з `imageio-ffmpeg`.

```bash
python -m venv .venv
.venv/Scripts/activate        # на Linux/macOS: source .venv/bin/activate
pip install -e ".[dev]"
```

Повний режим через OpenAI. Створи `.env` з `OPENAI_API_KEY=...` (приклад у `.env.example`) і запусти:

```bash
python -m reelgen "Нічна кав'ярня під дощем. Дівчина тихо каже: «Я повернулася, бо тільки тут мене ніхто не питає, чому я плачу.»" --out out/cafe.mp4
```

Ключ потрібен один. З нього береться LLM для сценарію і перевірки кадрів, генерація картинок, озвучка
і розпізнавання мови для перевірки, що репліку прочитали дослівно. Моделі можна поміняти через env.

Без ключів теж працює. Сценарій тоді пише Claude Code (якщо він встановлений і залогінений), персонажів малює
простий 2D-рендер, озвучує edge-tts:

```bash
python -m reelgen --demo --renderer puppet --writer claude "Помідор-ведучий на кухні каже огірку: «Термінові новини: з понеділка нас усіх закатують у банки!»"
```

Це режим для перевірки пайплайна, а не для красивої картинки. Нормальний 3D-вигляд дає тільки генеративна модель.

## Як писати ідею

Що в лапках (`"..."`, `«...»`, `“...”`), те й озвучується, без жодних змін. Кілька лапок дають кілька реплік,
голоси LLM розкидає сама. Якщо лапок немає, весь текст читається як закадровий голос.

## Що ще вміє

- Якщо щось впало посеред запуску, `--resume <run_id>` продовжить з того самого місця.
- `--from-stage images` перегенерує з потрібного етапу. Все, що не змінилось, береться з кешу.
- `--series examples/series/zucchini.json` задає «біблію серіалу»: герої виглядають і звучать однаково в усіх серіях.
- `python -m reelgen.evals run --label v1` проганяє набір тестових ідей, `evals compare` порівнює дві версії.
- `python scripts/check.py` запускає лінтер і тести. Той самий скрипт стоїть як Stop-hook для Claude Code,
  тож агент не може сказати «готово», поки щось червоне.

## Як воно влаштоване

```
parse → script → cast → voice → images → render → assemble → qa
```

Кожен запуск це папка `runs/<id>/`: там стан етапів (`state.json`), лог подій і всі проміжні файли. Найважливіше
рішення: LLM ніколи не пише текст репліки, а тільки посилається на неї за номером. Тому перефразувати вона її
фізично не може. Після озвучки STT перевіряє, що прозвучало саме те, що було в лапках.

Код лежить у `reelgen/`: `pipeline.py` (етапи), `models.py` (формати даних між етапами), `verbatim.py`
(робота з репліками), `providers/` (OpenAI, Claude Code, безкоштовні заглушки), `puppet.py` (2D-рендер).
Правила для coding-агентів у `CLAUDE.md`.
