# reelgen — тестове завдання AI Engineer (HOLYWATER)

## Завдання

HOLYWATER робить вертикальні серіали, повністю згенеровані AI: на вході сценарій, на виході змонтоване відео.
Треба показати, як я будую агентський пайплайн і harness, у якому агенти доводять задачу до кінця самі.

1. **Вибір стеку.** Запропонувати стек для автономного створення контенту (ідея → сценарій → готове відео),
   пояснити вибір, відкинуті альтернативи й ризики.
2. **Дата-флоу.** Етапи від сценарію до відео, артефакти й формати на кожному етапі, де зберігається стан
   і медіа, обробка помилок (ретраї, фолбеки, часткова перегенерація), точки human-in-the-loop.
3. **Метрики та оцінка якості.** Технічні метрики, метрики якості контенту (автоматичні й ручні), eval-процес
   (тестовий набір, регресійні прогони, порівняння версій), що запровадити в перший тиждень.
4. **MVP / PoC.** Агент: ідея на 1–3 речення → відео 8–30 секунд. Репліка має звучати **дослівно**, як у
   тексті на вході. Одна команда — один відеофайл.
5. **Як я працював з AI.** Інструменти, промпти й структурований вихід, де AI помилявся, експорт чату.

Здати: репозиторій з README, 1–2 приклади відео, нотатку з відповідями на частини 1–3, 5 і розділом
«що я зрізав і чому».

## Рішення

### Частина 4. PoC — зроблено

Одна команда, на виході відео:

```bash
python -m reelgen "Нічна кав'ярня під дощем. Дівчина тихо каже: «Я повернулася, бо тільки тут мене ніхто не питає, чому я плачу.»"
```

Як виконано вимогу «дослівно»: текст у лапках витягує код, а LLM посилається на репліку лише за номером і
фізично не може її переписати. Після озвучки STT перевіряє, що прозвучало саме те, що в лапках, слово в слово.

**Приклади** — міні-серіал «Кабачок-мільйонер», три серії по 15–20 секунд, згенеровані автоматично і без
жодних API-ключів: сценарій пише Claude Code, 3D-кадри малює локальна модель на RTX 4060, голос — edge-tts,
музика — MusicGen.

- [zucchini_ep1.mp4](examples/zucchini_ep1.mp4) — таємниця: багатий кабачок вирішує жити як бідний
- [zucchini_ep2.mp4](examples/zucchini_ep2.mp4) — насмішка: Помідора висміює «бідного» кабачка
- [zucchini_ep3.mp4](examples/zucchini_ep3.mp4) — викриття: кабачок виявляється власником пентхауса

### Частина 1. Стек

Workflow, а не вільний агент: дії систематичні, а агент непередбачуваний. Свій раннер замість n8n/low-code,
бо потрібні оркестрація і трейсинг. У проді Temporal, голос ElevenLabs, відео Veo 3, монтаж Remotion. Повна
таблиця з відкинутими варіантами й ризиками — [NOTES.md, Частина 1](NOTES.md#частина-1-вибір-стеку).

### Частина 2. Дата-флоу

```
parse → script → cast → voice → images → render → assemble → qa
```

Кожен етап пише артефакти в `runs/<id>/` і статус у `state.json`. Впав — `--resume` продовжує з того ж місця.
Бракований кадр чи репліка перегенеровуються окремо, решта береться з кешу. Сумнівні запуски отримують статус
`needs_review` і йдуть людині. Формати й обробка помилок — [NOTES.md, Частина 2](NOTES.md#частина-2-дата-флоу).

### Частина 3. Метрики

Технічні метрики пишуться в кожен запуск (успіх, ретраї, час етапів, виклики моделей). Якість: дослівність
(STT), валідність відео (тривалість, формат, звук), vision-суддя для кадрів. Eval: `python -m reelgen.evals run`
на фіксованому наборі ідей і `evals compare` для двох версій пайплайна.
Деталі — [NOTES.md, Частина 3](NOTES.md#частина-3-метрики-та-оцінка-якості).

### Частина 5. Робота з AI

Розробка йшла в Claude Code. `CLAUDE.md` задає правила для агента, а `scripts/check.py` (лінтер + тести) стоїть
Stop-хуком, тож агент не може сказати «готово», поки щось червоне. Реальні помилки AI і що я з ними робив —
[NOTES.md, Частина 5](NOTES.md#частина-5-як-я-працював-з-ai).

## Як запустити

Python 3.11+, ffmpeg окремо не потрібен.

```bash
python -m venv .venv
.venv/Scripts/activate        # на Linux/macOS: source .venv/bin/activate
pip install -e ".[dev]"
```

**З ключем OpenAI.** Створи `.env` з `OPENAI_API_KEY=...` і запусти команду з Частини 4. Ключ потрібен один:
LLM для сценарію і перевірки кадрів, картинки, озвучка, STT.

**Без ключів** (так зроблені приклади). Потрібні відеокарта NVIDIA і встановлений Claude Code:

```bash
pip install torch --index-url https://download.pytorch.org/whl/cu126
pip install diffusers transformers accelerate
python -m reelgen --demo --writer claude --images local \
  --series examples/series/zucchini.json --music assets/music/zucchini_theme.wav \
  "Гордовита Помідора висміює кабачка. Вона сміється: «Ти малий і бідний, кабачку.» Він відповідає: «Побачимо.»"
```

Корисне:
- `--resume <run_id>` — продовжити впалий запуск; `--from-stage images` — перегенерувати з етапу.
- `--series` — «біблія серіалу», герої однакові в усіх серіях.
- `--music` — фонова музика, яка стихає під репліками. Свою можна згенерувати: `python scripts/make_music.py "..."`.
- `python scripts/check.py` — лінтер і тести.

Код у `reelgen/`: `pipeline.py` (етапи), `models.py` (формати даних), `verbatim.py` (репліки),
`providers/` (OpenAI, Claude Code, локальні моделі), правила для агентів у `CLAUDE.md`.
